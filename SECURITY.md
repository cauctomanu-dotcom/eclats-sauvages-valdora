# Sécurité

Ne publie jamais de sauvegarde personnelle, d’adresse électronique privée, de mot de passe, de jeton GitHub ou de clé d’accès dans une issue.

Pour signaler discrètement une vulnérabilité, utilise la fonction **Security → Report a vulnerability** du dépôt GitHub si elle est activée. Décris le problème, sa conséquence et un parcours de reproduction minimal sans joindre de donnée personnelle.
